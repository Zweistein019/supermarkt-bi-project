# Supermarkt-bi-project

## Projektbeschreibung

Dieses Projekt ist ein Business-Intelligence-Projekt zur Analyse von Supermarktdaten.  
Ziel des Projekts ist es, Verkaufsdaten zu verarbeiten, in einer MySQL-Datenbank zu speichern und anschließend mit Power BI zu visualisieren und auszuwerten.

## Verwendete Technologien

- Python (Pandas)
- MySQL
- SQL
- Power BI

## Workflow
CSV-Daten
→ Datenbereinigung mit Python (Pandas)
→ Speicherung in MySQL
→ Erstellung von SQL-Views
→ Power-BI-Dashboard


## Key Features

- Datenbereinigung mit Python und Pandas
- Speicherung der Daten in MySQL
- Erstellung von SQL-Views für Reporting und Analyse
- Interaktives Dashboard in Power BI
- Analyse wichtiger KPIs:
  - Umsatz
  - Gewinn
  - Marge
  - Anzahl der Bestellungen
  - Durchschnittliche Bewertung
